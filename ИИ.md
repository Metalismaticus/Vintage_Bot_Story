# Подключение ИИ для управления ботом

Коротко: **да, есть, и способов два.** Оба уже написаны, оба включаются одной
переменной окружения и одним ключом запуска. Ни один из них не проверен живьём —
об этом честно сказано в конце.

> **Имя приложения сменилось 17.08.2026:** `TradeBot` → `VintageBotStory`
> (для людей — «Vintage Bot Story»). Команды и путь к `.exe` ниже даны уже
> по-новому; если в настройках MCP-клиента у вас прописан старый путь, его
> надо поправить руками — сам он не переедет.

| Способ | Кто принимает решения | Когда нужен |
|---|---|---|
| **Роль «ИИ»** (`--ai`) | нейросеть **внутри** бота: сама смотрит, сама ходит, сама отвечает в чат | бот живёт сам по себе — торгует, сторожит, болтает с игроками |
| **Режим MCP** (`--mcp`) | нейросеть **снаружи**: Claude Code или редактор водит бота руками | проверка модов, разовые опыты, «сходи туда и посмотри, что стало» |

Общее у них одно и главное: **и то и другое зовёт ТЕ ЖЕ умения, что человек в
чате и кнопки в окне управления**. Отдельного «мозга для ИИ» в боте нет и не
будет — список умений один, лежит в `VsBotKit/Agent/BotTools.cs`
(`BotToolbox.Standard`), и его же показывает вкладка «Умения» в окне управления.

---

## 1. Роль «ИИ»: бот думает сам

### Где задаются данные от ИИ

**В одном месте — в настройках роли «Под управлением нейросети».** Поставщик,
модель, глубина раздумья, длина разговора и потолок трат живут вместе
(`VsBotKit/AiSettings.cs`), и окно управления показывает их само, среди прочих
настроек роли. Второго места, где это задаётся, нет.

**Кроме ключа.** Ключ не хранится нигде: ни в настройках, ни в пресете, ни в
`bot.json`. Он живёт только в переменной окружения, и читает её сам SDK — бот
его не видит и наружу не отдаёт **никогда**. Всё, что он про ключ знает и
показывает, — «задан» или «не задан».

### Поддерживаемые поставщики («операторы»)

Список — не текст в этой справке, а **данные**: окно управления берёт их и
рисует выпадающим списком, а в чате тот же список печатает команда

```
!ии поставщики
```

Она же скажет по каждому, задан ли ключ **прямо сейчас** (да/нет — само
значение не печатается).

| Имя | Кто это | Переменная с ключом | Примеры моделей |
|---|---|---|---|
| `anthropic` | Anthropic (Claude), console.anthropic.com | `ANTHROPIC_API_KEY` | `claude-opus-5`, `claude-sonnet-5`, `claude-haiku-4-5` |
| `anthropic-token` | тот же Anthropic, но по временному токену входа (`ant auth login`) | `ANTHROPIC_AUTH_TOKEN` | те же |
| `совместимый` | любой сервис, отвечающий по протоколу Anthropic Messages | `ANTHROPIC_API_KEY` + адрес в `ANTHROPIC_BASE_URL` | спросите у него |
| `своя` | своя нейросеть, подключённая кодом (два метода `ILlmClient`) | не нужен | свои |

**Чего в списке нет и почему.** Список короткий не из скромности: у бота **один**
клиент нейросети, и говорит он по протоколу Anthropic Messages. Поэтому в окне
эти строки видны, но выбрать их нельзя — и там же написано, почему:

| Имя | Почему не поддержан |
|---|---|
| `bedrock` | Claude через AWS: нужен другой клиент (пакет `Anthropic.Bedrock`) и подпись запросов ключами AWS — к боту он не подключён |
| `vertex` | Claude через Google Cloud: нужен пакет `Anthropic.Vertex` и вход через `gcloud` |
| `openai` | OpenAI, Gemini и прочие: другой протокол обмена. Подключаются кодом — см. поставщика `своя` |

**`совместимый` живьём не проверен.** Ни одного запроса из этого проекта к
такому сервису ещё не сделано: адрес доносит до сети сам SDK по переменной
`ANTHROPIC_BASE_URL`. Проверять первым будете вы.

### Как включить

**Шаг 1. Положить ключ в переменную окружения.** Имя переменной — из таблицы
выше (у `anthropic` это `ANTHROPIC_API_KEY`). В файлы бот его не пишет
**никогда** и в журнал не печатает — читает переменную сам SDK.

```bat
rem Windows, на один запуск
set ANTHROPIC_API_KEY=sk-ant-...
```

```bash
# Linux / macOS, на один запуск
export ANTHROPIC_API_KEY=sk-ant-...
```

Если хотите, чтобы ключ пережил перезагрузку, — это ваше решение и ваша
ответственность: на Windows `setx ANTHROPIC_API_KEY sk-ant-...` кладёт его в
профиль пользователя, на Linux/macOS его обычно дописывают в `~/.profile`.
Бот в этом не участвует.

Ключ и адрес читаются **при запуске бота**: положили переменную — перезапустите
бота, иначе он её не увидит.

**Шаг 2. Выбрать роль.** Любым из трёх способов, они равнозначны:

```bash
dotnet run --project VintageBotStory -- --ai            # ключом запуска
```

```jsonc
// bot.json рядом с ботом
{ "ai": true }
```

Или в окне управления выбрать **«Под управлением нейросети»** и нажать «Вход».

### Что вы увидите, если что-то не так

Бот не молчит. До входа на сервер в журнал уходит либо это:

```
[ии] думаю: поставщик Anthropic (Claude), модель claude-opus-5, усилие low,
     потолок ответа 8192 токенов, память 40 сообщений, раздумье раз в 60 с
```

...либо честный отказ, где **каждая беда названа своей строкой** — их чинят по
одной, а не гадают, что из трёх сломалось:

```
[ии] НЕ ДУМАЮ: ключа нет: переменная окружения ANTHROPIC_API_KEY пуста
[ии] НЕ ДУМАЮ: модель не названа: настройка «Модель» пуста
[ии] Ключ кладут в переменную окружения ANTHROPIC_API_KEY ДО запуска бота: ...
```

Бывают ещё три: «поставщик не выбран» (настройка пуста), «поставщика „X“ не
знаю» (с перечислением тех, что бывают) и «адрес поставщика не задан:
переменная ANTHROPIC_BASE_URL пуста» — последняя только у `совместимый`.

Во втором случае бот **всё равно войдёт в мир и будет жить**: рефлексы
выживания работают, команды чата работают. Он просто не тратит деньги на
заведомо неудачные запросы — раньше он долбился бы в сеть раз в минуту всю ночь.

В чате состояние спрашивают командой:

```
!ии              что за поставщик и модель, сколько потрачено, можно ли тратить дальше
!ии поставщики   весь список: имя, переменная с ключом, есть ли ключ, примеры моделей
!ии стоп         перестать думать (бот остаётся живым)
!ии пуск         думать снова (с перепроверкой ключа)
!ии забудь       забыть потраченное, лимиты считаются заново
```

### Настройки

Все они — **свойства роли**, поэтому окно управления показывает их само, без
единой правки в панели. Крутить можно на ходу; характер, дело и правила бот
доносит до модели сам, пересобирая подсказку через пару секунд после правки.

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `Характер` | обычный игрок | кто этот бот и как говорит |
| `Цель` | держаться места, отвечать игрокам | чем занят, пока его не трогают |
| `Правила` | не уходить дальше 200 блоков, чужое не трогать | запреты хозяина |
| `ДуматьРазВСекунд` | 60 | как часто думать без повода (0 — только по событиям) |
| `ОтвечатьВЧате` | да | отвечать ли на сообщения игроков |
| `ДействийЗаХод` | 12 | сколько действий подряд за один ход |
| `РефлексыВыживания` | да | подключать рефлексы (меняется только до запуска) |
| `Поставщик` | `anthropic` | кто даёт модель; список — `!ии поставщики` |
| `Модель` | `claude-opus-5` | какая модель думает |
| `Усилие` | `low` | `low`, `medium`, `high`, `max` — глубина раздумья |
| `ПотолокОтвета` | 8192 | токенов на ход; раздумье и текст делят его пополам |
| `ПомнитьСообщений` | 40 | длина разговора; больше память — дороже каждый ход |
| `Магазин` | нет | поднять лавку и дать два умения поверх неё |
| `ОбращенийВЧас` | 60 | жёсткий потолок обращений |
| `ТокеновВСутки` | 1 000 000 | жёсткий потолок токенов |
| `ЦенаВходаЗаМиллион` / `ЦенаВыходаЗаМиллион` | 0 (не знаем) | впишите тариф — бот сам посчитает расход в деньгах |
| `Валюта` | `$` | подпись в сводке |

**Про `Магазин`.** По умолчанию выключен: роль называется «Под управлением
нейросети», и человек, выбравший её в окне, ждёт обычного бота, а не продавца,
который требует размеченной табличками лавки. Включите ручку — поднимется
механизм магазина, появятся умения `shop_status` и `shop_round`, а характер
сменится на лавочника Кузьму (только если вы не переписали его сами). Обратно
не выключается: способность продавца уже в теле бота, и роль скажет об этом
вслух, а не сделает вид, что убрала её.

### Что оно может

Ровно то же, что человек: около трёх десятков умений (точный список — во
вкладке «Умения» окна управления). Смотреть по сторонам, говорить, ходить,
брать высоту столбом и лестницей, спускаться, читать таблички, честно
открывать сундуки, брать предмет в руку, ломать и ставить блоки, бить, есть,
собирать ягоды, разводить костёр, прятаться от бури, ждать. Плюс всё
копательское: наряд «принеси двадцать меди», карьер, ход, разведка под землёй,
дорога, вынос на склад, проверка и пополнение запасов.

### Чего оно НЕ может

- **Ничего сверх человека.** Телепорта нет, зрения сквозь стены нет,
  содержимого закрытого сундука не видно, мгновенной добычи нет. Всё нечестное
  живёт за флагом `Cheats` и по умолчанию выключено; нейросети он не выдаётся.
- **Спасать себя.** Не висеть в воздухе, отбиться от волка, поесть, полечиться,
  спрятаться от бури — это детерминированные рефлексы. Модель не должна думать
  три секунды, пока бота едят.
- **Работать без ключа.** См. выше: честный отказ, а не тихое ничегонеделание.
- **Менять рефлексы на ходу.** `РефлексыВыживания` читается один раз, при
  выборе роли; роль об этом предупреждает в журнале.

### Во что это обходится

Каждое «подумать» — платный запрос. Считайте так:

- **Один ход** = системная подсказка + описание всех умений + история
  разговора + снимок обстановки + ответ модели. Первый ход дороже (кэш пуст),
  дальше вход частично идёт по кэшу.
- **Сколько ходов в час.** При `ДуматьРазВСекунд = 60` бот думает раз в минуту от
  скуки плюс на каждое сообщение игрока и на каждое важное событие (началась
  буря, погиб). Потолок по умолчанию — **60 обращений в час** и **миллион
  токенов в сутки**; при 80 % израсходованного бот сам начинает думать вчетверо
  реже, а на исчерпании встаёт и говорит об этом в журнал.
- **Деньги.** Бот считает их только если вы задали тариф. Прейскурант Anthropic
  на день написания, за миллион токенов:

  | Модель | Вход | Выход |
  |---|---|---|
  | `claude-opus-5` | 5 $ | 25 $ |
  | `claude-sonnet-5` | 3 $ | 15 $ |
  | `claude-haiku-4-5` | 1 $ | 5 $ |

  Запись в кэш дороже входа в 1,25 раза, чтение из кэша — в 10 раз дешевле.
  Проверьте актуальные цены у поставщика и впишите их в `ЦенаВходаЗаМиллион` и
  `ЦенаВыходаЗаМиллион` — сами цифры бот не выдумывает и без них честно говорит
  «цену не считаю».

Дешевле всего: `Усилие = low` (стоит по умолчанию), `ПомнитьСообщений`
поменьше, `ДуматьРазВСекунд` побольше, модель попроще (`claude-haiku-4-5` в пять раз
дешевле опуса). Дороже всего — `Усилие = max` и длинная память.

## 2. Режим MCP: ботом правит внешний клиент

Бот становится MCP-сервером и отдаёт свои умения любому MCP-клиенту — Claude
Code, редактору, своему скрипту. Обмен идёт по stdin/stdout процесса, поэтому
**журнал в этом режиме пишется только в файл** (папка `logs`): в stdout живёт
протокол, и одно лишнее слово туда ломает связь.

### Как включить

```bash
dotnet build VintageBotStory
```

и прописать в настройках MCP-клиента **собранный exe, а не `dotnet run`**
(`run` запускает программу дочерним процессом и не пробрасывает ей stdin —
протокол молчит; проверено живьём):

```json
{
  "command": "C:\\путь\\к\\Бот TOPS\\VintageBotStory\\bin\\Debug\\net10.0\\VintageBotStory.exe",
  "args": ["--mcp"]
}
```

Готовый батник — `start-bot-mcp.bat` (и `start-bot-mcp.sh`).

### Что доступно клиенту

Тот же набор умений плюс четыре для разработки модов:

| Умение | Зачем |
|---|---|
| `inspect_block` | всё, что бот знает о блоке, включая данные блок-сущности мода |
| `watch_block` | подождать, пока блок изменится, — проверка реакции мода |
| `server_command` | отправить команду сервера от лица бота (сработает, только если у бота есть права; это обычный чат, а не чит) |
| `chat_tail` | последние строки игрового чата — там сервер отвечает на команды |

### Честный отказ

Роль «Под внешним управлением» можно выбрать и в окне управления — но сервер
при этом **не поднимется**, потому что stdin занят запуском. Раньше это
выглядело как живой бот, который ничего не делает и молчит о причине. Теперь в
журнале появляется:

```
[mcp] ВНЕШНЕГО КЛИЕНТА НЕТ: роль выбрана без ключа --mcp, сервер не поднят.
      Бот будет просто жить и слушать команды чата. ...
```

В чате то же самое спрашивают командой `!mcp`.

Настройки роли: `Здороваться` (общая ручка всех живущих ролей; у MCP умолчание
своё — не здороваться, в проверках мода лишний шум ни к чему) и `РадиусЗаЕдой`
(по умолчанию 16 блоков: клиент оставил бота у своего блока и ждёт его там,
а не в тридцати клетках у малинника).

**Ключа нейросети у этой роли нет и быть не должно** — за думанье платит тот,
кто подключился. Поставщик, модель и потолок трат задаются у роли «Под
управлением нейросети»; роль говорит об этом в журнале при сборке, чтобы никто
не искал здесь поле для ключа.

## 3. Чем это НЕ является

- **Не «бот сам всему научится».** Нейросеть только выбирает, что и когда
  сделать, из готового списка умений. Новое умение — это код в библиотеке, а не
  просьба к модели.
- **Не бесплатно.** См. раздел о расходах.
- **Не проверено живьём.** Ни одного запроса к нейросети из этого проекта ещё
  не сделано: это платный вызов на ключе владельца. Собрано, покрыто тестами
  разбора истории разговора, бюджета и настроек — но первый настоящий прогон за
  вами. Это относится и к поставщику `совместимый`: адрес из
  `ANTHROPIC_BASE_URL` доносит до сети сам SDK, и таким путём бот ещё не ходил.
- **Не витрина всех поставщиков сразу.** Клиент у бота один, протокол один —
  Anthropic Messages. Bedrock, Vertex, OpenAI и Gemini в списке видны, но
  выбрать их нельзя, и рядом написано, чего для них не хватает.
- **Не защита от чужого клиента.** Кто подключился к MCP-серверу по stdio, тот
  и водит бота. Ставьте его так же осторожно, как любой другой инструмент
  разработчика.
